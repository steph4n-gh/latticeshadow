# Security policy

LatticeShadow is a development prototype and has not had an independent security
review. Do not use it as the sole protection for sensitive information. Automatic
capture can store clipboard and terminal content; it is opt-in.

Please report suspected vulnerabilities privately through this repository's
[GitHub vulnerability reporting form](https://github.com/steph4n-gh/latticeshadow/security/advisories/new).
Include a clear impact description, reproduction steps, affected versions or
commits, and any suggested fix. Do not post exploit details in a public issue.

We will triage reports and coordinate a fix and disclosure with the reporter.
There is no published response-time or support guarantee. The latest source on
`main` is the only maintained line during the prototype stage.
